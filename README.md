# Yohaku-Reminder

## 現在の構成

- Expo app の最小構成
- `develop` ブランチ運用
- GitHub Actions での iOS ローカルビルド
- Apple signing / submit 用ドキュメント

- `eas.json`

- `docs/ios-signing-secrets-setup.md`
