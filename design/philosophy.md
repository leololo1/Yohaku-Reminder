# Yohaku Reminder Design Philosophy

Yohaku Reminder is a quiet, minimal reminder app.

The app must feel like a blank white space where only necessary reminders are placed gently.

Do not design for maximum productivity. Design for stillness, clarity, restraint, and visual beauty.

The app should feel:

- white
- quiet
- spacious
- refined
- calm
- almost empty
- intentionally minimal

The core principle is:

> Remove anything that does not need to exist.

Yohaku Reminder is not a busy task manager.
It is not a colorful productivity app.
It is not a habit tracker.
It is not a dashboard.

It is a white reminder app for people who want to remember only what matters.

---

## Design Decision Rule

When adding any UI element, ask:

1. Is this necessary for adding, seeing, editing, or completing a reminder?
2. Can the user understand the screen without this?
3. Does this reduce the feeling of white space?
4. Does this make the app feel like a normal busy task app?
5. Would removing it make the design more Yohaku?

If the element is not necessary, remove it.

If there is a conflict between utility and visual restraint, prefer visual restraint unless the app becomes unusable.

---

## Copywriting

Text must be short and quiet.

Use simple Japanese.

Good:

```text
今日
```

```text
あとで
```

```text
通知
```

```text
完了
```

Avoid:

- long explanations
- motivational copy
- casual jokes
- productivity buzzwords
- urgent language
- excessive empty-state guidance

Do not over-explain the UI.

---

## App Identity

App name:

```text
Yohaku Reminder
```

Yohaku series should share:

- white background
- quiet typography
- minimal controls
- no unnecessary color
- large margin
- restrained interaction

---

## Final Direction

Yohaku Reminder should feel like:

- a blank page
- a quiet room
- a white notebook
- high-end stationery
- a calm place to leave future thoughts

It should not feel like:

- Apple Reminders copied directly
- a productivity dashboard
- a colorful task manager
- a kanban board
- a habit tracker

The goal is not to manage everything.

The goal is to remember only what matters.
