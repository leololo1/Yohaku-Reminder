# Yohaku Reminder Design Tokens

## Visual Direction

Use:

- white and off-white backgrounds
- very light gray shadows
- thin lines
- soft rounded corners
- large empty spaces
- small and quiet typography
- minimal icons
- monochrome UI

Avoid:

- strong colors
- gradients
- decorative illustrations
- colorful priority labels
- heavy borders
- bold cards
- dense layouts
- dashboard-like UI
- playful animations
- excessive explanations

The design should look closer to high-end stationery than a typical reminder app.

---

## Colors

Use only neutral colors.

### Background

Primary background:

```text
#FAFAF8
```

Surface background:

```text
#FFFFFF
```

Subtle surface:

```text
#F7F7F5
```

### Text

Primary text:

```text
#222222
```

Secondary text:

```text
#777777
```

Tertiary text:

```text
#AAAAAA
```

Disabled text:

```text
#CFCFCB
```

### Lines and Borders

Hairline border:

```text
#EEEEEA
```

Subtle divider:

```text
#E6E6E2
```

### Accent

Use almost no accent color.

If an accent is absolutely necessary, use a very soft neutral gray.

```text
#DCDCD8
```

Danger actions may use a muted red only when necessary:

```text
#B85C5C
```

Use danger color sparingly.

---

## Typography

Typography must be thin, calm, and understated.

Use the system font.

Font weight:

- Regular
- Light
- Medium only when necessary

Avoid:

- Bold headings
- Heavy typography
- Large labels
- Decorative fonts

### Text Sizes

App title:

```text
16-18pt
weight: regular
```

Date group title:

```text
13-15pt
weight: regular
color: secondary
```

Reminder title:

```text
15-17pt
weight: regular
```

Reminder time:

```text
12-13pt
weight: regular
color: secondary
```

Detail labels:

```text
12-13pt
color: secondary
```

The UI should never feel loud.

---

## Spacing and Layout

Spacing is the main design element.

Use generous margins and vertical breathing room.

### General Rules

- Outer screen margin: 28-32pt
- Section spacing: 24-40pt
- Row height: 56-78pt
- Form row spacing: 18-28pt
- Do not fill empty space just because it exists

Empty space is part of the design.

Do not compress content to show more information.
Do not add extra labels to explain obvious things.

---

## Shadows

Use shadows very softly.

Shadows should create depth without looking like material cards.

Example:

```text
shadow color: #000000
opacity: 6-10%
blur: 20-40
y: 8-16
```

Avoid dark shadows.

---

## Border Radius

Use large soft corners.

Floating buttons:

```text
999pt
```

Reminder completion mark:

```text
999pt
```

Sheets:

```text
24-34pt
```

Corners should feel soft but not cute.
